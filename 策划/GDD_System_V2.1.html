《潜抑》系统策划案

版本：2.1 日期：26/1/30

核心循环与数值系统

1.1. 基础数值系统

本模块定义了驱动游戏进程和限制玩家行为的核心变量。

1.1.1应激度

  • 定义：衡量主角林顾念心理承受能力的动态数值，是游戏核心生存指标 。

  • 数值逻辑：

    • 增加机制 ：现实世界行为，在现实世界中整理物品（触发记忆、回忆）时增加 。
    • 环境影响：现实世界的探索会增加应激值 。

  • 减少机制 ：

    • 日常行为调节：使用娱乐系统（抽烟、阅读、电子游戏）或进行居家活动（睡觉、吃饭、洗漱）
    • 专业干预调节：在意识世界进行治疗训练（咨询对话、认知行为疗法、自由绘画）。

  • 系统影响：

    • 对话框锁定：高应激度会锁定咨询室内的特定对话选项，限制回复内容的动态变化 。
    • 线索生成：核心线索通常仅在低应激度状态下才会出现在选项框中 。低应激度状态在意识世界下指该数值在 1 - 30 区间内。

  • 解离度关联：应激值的变化直接影响解离度数值 。

1.1.2 解离度

  • 定义： 衡量主角现实认知与潜意识边界模糊程度的数值 。

  • 数值逻辑：

    • 依赖关系：由应激度的变化驱动，当应激度超限（低于0、高于100），造成解离度增减。特殊的，通过药物可以直接改变解离度。

  • 系统影响：

    • 世界切换阈值：决定玩家能否通过床这一媒介进行现实与意识世界的切换 。

      强制切换：极端状态将触发被动切换 。极端状态：解离度数值在 1 - 10 区间时进入现实世界，数值在 91 - 100 区间时进入意识世界。

    • 画面表现：随解离度上升，画面灰度逐渐增大，在该数值落在 91-100区间画面几乎看不见。

1.2 核心循环机制

本模块定义游戏的宏观叙事推进与微观玩法循环。

1.2.1 宏观叙事循环

该循环驱动游戏剧情的实质性推进，形成 获取-验证-重构 的闭环。

阶段一：意识世界 (获取线索)

  • 场景：陆云医生咨询室 。
  • 行为：接受心理咨询，通过对话与训练降低应激度，解锁并获取关键线索 。

阶段二：回归现实 (寻找触媒)

  • 场景：林顾念新家、老房子等现实场景 。
  • 行为：携带意识世界的线索，在现实中寻找对应的“物品”，并开始回忆。

阶段三：重构记忆 (解开真相)

  • 触发：获得物品后触发“记忆回忆” 。
  • 行为：回溯至关键时间点（如2014年4月15日案发日），补全剧情拼图 。
  • 闭环：回忆提供的信息解锁新的意识世界探索内容 。

1.2.2 微观玩法循环

该循环主要发生在日常场景中，玩家需维持心理稳态以支持主线推进。

  • 资源博弈：

    • 玩家为了推进剧情（获取线索），必须保持低应激度 。玩家为了验证真相（整理物品/探索现实），必然导致应激度增加。

  • 调节手段：

    • 利用娱乐系统进行数值平衡 。
    • 利用药物机制强制干预现实与意识的转换 。

  • 循环目标：最大化线索获取效率 。

双重世界交互系统

2.1 意识世界交互系统

场景定义：主角的自我构建世界，核心场景为“陆云医生咨询室”。核心目标：接受咨询，寻找线索，降低应激度 。

2.1.1 咨询对话系统

  • 机制描述：玩家与陆云医生进行交互，通过对话框选择回复。

  • 核心机制：动态选项：

    • 正常状态：出现常规回复选项，用于推进剧情和建立信任 。
    • 应激锁定 ：当应激度过高时，系统会锁定部分理性的对话框，限制回复选项，导致玩家无法获取关键信息或新线索 。

  • 产出：低应激度下产生剧情线索。

2.1.2 心理诊疗玩法集群

该模块在“陆云医生咨询室”场景中触发，作为调节数值和叙事推进的主要手段。形式设计如下。

2.1.2.1 自由绘画疗法

玩法类型：描红/轨迹跟随

核心逻辑：

  • 输入：鼠标长按拖拽（PC）。

  • 交互规则：

    1. 屏幕显示一幅只有虚线轮廓的画作（模板）。
    2. 玩家需控制画笔沿着虚线轨迹移动。
    3. 系统实时检测画笔坐标与模板轨迹的偏差。若偏离超过阈值（如判定区宽度），线条变淡或断裂。

  • 资源需求：需美术提供不同心理阶段的线稿模板。

产出：完成度 > 80% 视为成功，获得任务线索/道具，稳态系统数值变动。完成度低回退初始状态重新描绘，不设置失败判罚。

2.1.2.2 沙盘疗法

玩法类型：物品摆放与场景构建 （拖放构建）

核心逻辑：

  • UI布局：屏幕下方为沙具栏（物品栏），上方为“沙盘区域”。

  • 输入：鼠标长按拖拽、点击。

  • 交互规则：

    1. 玩家从下方拖拽沙具（房屋、人物、动物等模型）至上方沙盘，摆放完成后点击提交。

    2. 上下限处理：避免玩家运气好过快推进得到任务道具，以及避免玩家长时间卡关。

      下限：一个治疗流程内（即单一进度内）随玩法次数进行，物品栏中可选择沙具数量越来越少，即做出正确选择组合概率递增。

      上限：首次进行该玩法物品栏中没有完成所需的沙具，限制进度。

    3. 位置判定：物品放置需符合物理层级（如：人不能悬空，需放在沙面上），如有重叠需进行层级排序。

  • 资源需求：需美术提供不同心理阶段的模板。

产出：摆放的特定沙具组合推进剧情进度，获得任务线索/道具，稳态系统数值变动。不符合组合，稳态数值降低判罚，回退剧情流程。

2.1.2.3 延长暴露疗法

玩法类型：碎片拼图

核心逻辑：

  • 输入：鼠标长按拖拽（PC）。

  • 交互规则：

    1. 画面被破碎成若干拼图碎片。不作时间限定。
    2. 缺片机制：如果玩家在现实世界未收集到关键线索/未持有关键道具，拼图中会缺失关键碎片，无法完成拼图判定为回避创伤疗法失败，应激值不降反升，需返回现实寻找线索。

  • 资源需求：需美术提供不同心理阶段的拼图模板。

产出：拼图完整且复原成功，获得任务线索/道具，稳态系统数值变动。拼图未完成，稳态数值降低判罚，回退剧情流程。

2.1.2.4 认知加工疗法

玩法类型：多叉树迷宫

核心逻辑：

  • 输入：WASD探索（PC）。

  • 交互规则：

    1. 起点与终点：从固有思维链条起点出发，探索迷雾，试图抵达理性认知（终点）。
    2. 多叉选择：每个节点有多个分支，代表不同的念头。
    3. 错路排除：若选择了错误的逻辑分支（死胡同），画外音提示后路径会表现为破碎，玩家需退回上一节点重选。
    4. 无失败判定：该玩法不做失败判罚，旨在让玩家通过试错体验纠正认知的过程，直到走通为止。

  • 资源需求：需美术提供玩法迷宫背景模板。

产出：抵达终点视为成功，获得任务线索/道具，稳态系统数值变动。

2.1.3 环境调查

  • 机制描述：在咨询室场景内点击探索，寻找隐藏在环境中的非对话类线索 。

2.2 现实世界交互系统

场景定义：林顾念新家、老房子（案发核心场景）、通勤路线等 。核心目标：寻找触媒物品，重构记忆，但需承受压力 。

2.2.1 任务物品高亮与合成

本模块定义物品的获取、合成及任务指引逻辑。

2.2.1.1 物品合成

  • 逻辑：特定物品 A + 物品 B = 物品 C

  • 交互：在背包 UI 中，拖拽一个物品重叠到另一个物品上触发合成。

  • 细节补充： 当玩家拖拽物品A并悬停在物品B上方时：

    • 若可合成： 物品B的边框高亮显示（绿色/金色），松手即触发合成。
    • 若不可合成： 物品B的边框显示红色或无反应，松手后物品A弹回原位。
2.2.1.2 任务高亮
  • 触发条件：当前任务/流程需要特定物品进行交互时，对所持有的物品格高亮提示，若所需为合成物品，对合成材料高亮提示。
  • 具体表现：如果物品已在背包，打开背包时，该物品图标边框会有呼吸灯效果（高亮），提示玩家现在该用这个了。

2.2.3 娱乐与日常系统

  • 交互对象：手机、电脑游戏、书籍、香烟、床、洗漱台 。

  • 功能：

    • 信息获取：查看手机/电脑获取现实线索 。
    • 数值调节：进行娱乐活动（抽烟、看书）可降低意识世界的应激值。

【*TBD 】UI与HUD系统

本模块定义玩家在游戏过程中看到的所有界面元素及其逻辑。

3.1 核心HUD

常驻于屏幕上的界面元素。

布局风格：沉浸式，极简风格。

3.1.1 状态栏

位置：屏幕左上角。

  • 应激度表现：

    • 形式：不使用传统的红色血条，使用心电图波形或大脑轮廓的填充度。
    • 反馈：数值升高时，波形频率加快/颜色由冷变暖（蓝->红）；数值 > 80 时，边缘出现故障抖动效果。

  • 解离度表现：

    • 形式：通过全屏滤镜表现，不设显性 UI 条。

帮助玩家进行所在世界的判断。

  • 形式：非显性指引，在场景细节中隐藏两个世界的区别。

3.2 功能界面

3.2.1 背包/手机界面

  • 入口：按住Tab或按下B键呼出.

  • 布局逻辑：

    • 左侧 （2/3）：物品栏网格。显示所有持有的现实物品和意识碎片，二者分立上下两个分片区。

      • 鼠标悬于物品上方 1.5 秒，或单击物品时，鼠标旁显示物品大图和描述文本。

    • 右侧 （1/3）：手机系统。

      • 切换标签页可进入不同界面，查看任务目标、进行手机娱乐、。

3.2.2 【*TBD 】对话框系统

  • 样式：

    • 现实世界：漫画式气泡对话，跟随角色/NPC头部。尾巴指向发话者头部。背景纯白，黑字。
    • 咨询室：底部通栏式 AVG 对话框，强调沉浸感。屏幕底部 1/3 处的通栏半透明黑底对话框。左侧显示立绘/头像，右侧显示文本。

  • 【*TBD 】应激锁定表现：

    • 当应激度过高时，特定的回复选项会被黑色涂抹或文字乱码化，鼠标悬停时会有焦躁的音效，且无法点击。

3.2.3 交互提示

  • 位置：跟随场景中的可交互物体。
  • 形式：当玩家靠近可交互物体（距离 < 1.5米）时，物体上方浮现白色小圆点或按键提示[F] [交互文本]。

3.2.4 疗法结算界面

  • 触发时机：任意心理疗法小游戏结束后。

  • 包含元素：

    1. 结果评级：以心理评估单的形式呈现。
    2. 数值变化：动态演示应激度/解离度变动的动画。
    3. 获得奖励：若胜利判定成立，展示获得的关键线索图标以及名称。
