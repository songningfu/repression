# 对话系统使用说明

## 1. 用途

对话系统用于实现：

- 基于 `CSV` 的节点/选项对话
- 根据当前 `Stress` 过滤选项
- 选择后回写 `Stress`
- 在固定对话面板中显示文本、选项与头像


## 2. 需要的脚本

核心脚本位于：

- `Assets/Scripts/Dialogue/DialogueRunner.cs`
- `Assets/Scripts/Dialogue/DialogueView.cs`
- `Assets/Scripts/Dialogue/DialogueChoiceButtonView.cs`
- `Assets/Scripts/Dialogue/DialogueTrigger.cs`
- `Assets/Scripts/Dialogue/DialogueFInteractController.cs`
- `Assets/Scripts/Dialogue/DialogueGraphData.cs`
- `Assets/Scripts/Dialogue/DialogueCsvImportDefinition.cs`


## 3. 先准备资源

在 Unity 里先创建以下资源：

1. `DialogueCsvImportDefinition`
2. `DialoguePortraitLibrary`（如果需要头像）

配置方式：

- 把 `DialogueNodes.csv` 绑定到 `Nodes Csv`
- 把 `DialogueChoices.csv` 绑定到 `Choices Csv`
- 填写 `Graph Id`
- 在 `DialogueCsvImportDefinition` Inspector 点击 `生成 / 更新 DialogueGraphData`

结果：

- 会生成一个 `DialogueGraphData` 资源
- 之后 `DialogueRunner` 直接引用这个资源运行


## 4. 场景中需要的对象

### 4.1 对话运行器

在场景中准备一个对象，例如：

- `DialogueSystem`

挂载：

1. `DialogueRunner`

需要绑定：

- `graph`：拖入上一步生成的 `DialogueGraphData`
- `view`：拖入场景中的 `DialogueView`
- `mentalStatsManager`：拖入现有 `MentalStatsManager`


### 4.2 对话面板

在 Canvas 下准备一个固定面板，例如：

- `DialoguePanel`
  - `PortraitImage`
  - `SpeakerNameText`
  - `DialogueText`
  - `NextButton`
  - `ChoicesRoot`

在 `DialoguePanel` 上挂：

1. `DialogueView`

需要绑定：

- `panelRoot`：对话面板根节点
- `portraitImage`：头像 `Image`
- `speakerNameText`：名字 `TMP_Text`
- `dialogueText`：正文 `TMP_Text`
- `choicesRoot`：选项按钮父节点
- `choiceButtonPrefab`：选项按钮预制体
- `nextButton`：下一句按钮
- `nextButtonLabel`：下一句按钮上的 `TMP_Text`
- `uiAudioSource`：如果需要打字音和点击音就绑定


### 4.3 选项按钮预制体

需要提前做一个按钮 Prefab，并挂：

1. `Button`
2. `TMP_Text`
3. `DialogueChoiceButtonView`

需要绑定：

- `button`：按钮组件本体
- `label`：按钮文字 `TMP_Text`


## 5. 如何触发对话

有两种常用方式：

### 方式 A：直接从代码调用

拿到 `DialogueRunner` 后调用：

```csharp
runner.StartDialogue("100");
```

适合：

- 剧情事件
- 任务系统
- 自定义交互逻辑


### 方式 B：挂 `DialogueTrigger`

在需要触发对话的对象上挂：

1. `DialogueTrigger`

需要绑定：

- `runner`
- `startNodeId`

可选：

- 勾选 `triggerOnStart`：场景启动自动播
- 勾选 `oneShot`：只触发一次

### 方式 C：玩家靠近后按 F 对话

在需要交互的对话物体上挂：

1. `Collider2D`
2. `DialogueTrigger`
3. `DialogueFInteractController`

需要补齐：

- `Collider2D` 必须勾选 `Is Trigger`
- `DialogueTrigger.runner`
- `DialogueTrigger.startNodeId`

建议补齐：

- 在该物体下创建一个默认隐藏的提示子物体，命名为 `按F对话`
- 或者直接把提示对象拖到 `DialogueFInteractController.promptRoot`

运行效果：

- 玩家进入触发范围时显示“按F对话”
- 玩家按下 `F` 后调用 `DialogueTrigger.TryStartDialogue()`
- 对话进行中自动隐藏提示，对话结束后若仍在范围内会再次显示


## 6. 与应激度系统的关系

对话系统不会直接写 UI 数值。

实际流程是：

1. `DialogueRunner` 读取 `MentalStatsManager.CurrentStress`
2. 按 `ThresholdLow / ThresholdHigh` 过滤选项
3. 玩家选择后调用 `MentalStatsManager.ModifyStress(...)`

所以必须保证场景里已有可用的：

- `MentalStatsManager`


## 7. 最小验证流程

1. 导入 CSV，成功生成 `DialogueGraphData`
2. 在场景中搭好 `DialogueRunner + DialogueView + 选项按钮 Prefab`
3. 绑定 `MentalStatsManager`
4. 调用 `StartDialogue("100")`
5. 确认文本能显示、下一句能推进、选项会按应激度变化、点击选项后能跳转


## 8. 常见问题

### 点了没反应

优先检查：

- `DialogueRunner.graph` 是否为空
- `startNodeId` 是否存在于 `DialogueNodes.csv`
- `DialogueView` 上的 `nextButton` / `choiceButtonPrefab` 是否已绑定
- 如果是 F 键交互，检查 `Collider2D.IsTrigger` 是否已勾选，以及玩家是否带 `Player` Tag


### 选项不显示

优先检查：

- 当前节点是否真的有选项
- 当前 `Stress` 是否落在 `ThresholdLow ~ ThresholdHigh` 内
- `ChoicesRoot` 是否绑定正确
- 选项按钮 Prefab 是否挂了 `DialogueChoiceButtonView`


### 头像不显示

优先检查：

- `DialogueView.portraitLibrary` 是否已绑定
- `PortraitKey` 是否和 `DialoguePortraitLibrary` 中的 key 一致
