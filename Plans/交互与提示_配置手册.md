# 交互与提示 配置手册（给场景物体加"按F对话 / 头顶氛围提示"）

> 面向策划/美术/程序，在 Unity Inspector 里手动配置。以 `Reality_Room` 的冰箱为标准样板。
> 最后更新：2026-06-07。

---

## 0. 前置（每个场景只做一次）

1. 场景里要有一份 **Dialogue 面板**：把 `Assets/Prefabs/Dialogue/Dialogue.prefab` 拖进场景。
   - 选中它下面挂 `DialogueRunner` 的对象（`DialogueSystem`），把 `Graph` 设成本幕的对话图（房间用 `Assets/Resources/dialogue/Act1/Act1_Room.asset`）。
   - `MentalStatsManager` 不用管，运行时会自动创建。
2. **玩家**身上要有头顶气泡（只配一次，全场景共用）：
   - 玩家根物体加 `PlayerPromptReceiver`。
   - 玩家下建一个子物体 `PromptBubble`，加 `TextMeshPro`(3D) + `PlayerPromptView`，把那个 TMP 拖给 `PlayerPromptView.promptText`。
   - 把 `PlayerPromptView` 拖给 `PlayerPromptReceiver.promptView`。
   - 位置：拖到角色头顶。

---

## 1. 给物体加「按 F 对话」

> 适用：冰箱、书桌、床头柜、手机、镜子……任何要弹对话的物体。

**步骤**
1. 选中物体，加 `Box Collider 2D` → **勾选 Is Trigger**，调大到玩家能走进的范围。
2. 加 `InteractableObject`（项目统一交互组件）。
3. 加 `DialogueTrigger`：
   - `Start Node Id` 填对话入口号（见下表）。
   - `One Shot` **取消勾选**（日常物体可反复交互）。
4. 把对话接到交互事件：在 `InteractableObject` 的 **On Interact (UnityEvent)** 里点 `+`，
   - 把**这个物体自己**拖进对象槽，
   - 下拉选 `DialogueTrigger → TryStartDialogue ()`。
5. 做「按F」提示子物体：
   - 物体下建子物体，**命名为 `按F`**（或 `按F查看`/`按F对话`——这些名字会被自动识别）。
   - 加 `TextMeshPro`(3D)，文字写"按 F 查看"，拖到物体上方。
   - **取消勾选该子物体的 Active（默认隐藏）**。
   - （`InteractableObject.promptRoot` 留空即可，它会按名字自动找；也可手动把子物体拖进去。）

**第一幕房间各物体的 Start Node Id**

| 物体 | Start Node Id |
|---|---|
| 冰箱 | `11200` |
| 书桌·小说 | `11300` |
| 书桌·抽屉 | `11340` |
| 床头柜·香烟 | `11400` |
| 手机 | `11500` |
| 镜子 | `11100` |

> 想加新对话？在 `Assets/Resources/dialogue/Act1/Act1_Room_Nodes.csv` / `_Choices.csv` 里加节点，再到 `Act1_Room_ImportDef` 的 Inspector 点"生成/更新"重导，然后用新 NodeId。

## 2. 给物体加「头顶氛围提示」（靠近自动冒短句）

> 适用：任何物体，包括纯装饰（沙发、收音机、花瓶、日历）。和「按F对话」可以同时加。

**步骤**
1. 选中物体，确保有 `Collider2D` 且 **Is Trigger** 勾选（和对话共用同一个碰撞体即可）。
2. 加 `PromptSource`：
   - `Prompt Texts`：填一句或多句提示词（角色内心独白风格）。
   - `Trigger Chance`：氛围物体 `0.3~0.4`，想强引导的 `0.6~1.0`。
   - `Show Duration` ≈ `1.6`，`Cooldown Seconds` ≈ `0.8`，`Priority` 关键物体调高。
3. 完成。靠近时玩家头顶按概率冒出对应短句（共用第 0 节配的那个气泡）。

---

## 3. 门（场景切换）

门用 `SceneDoor`（左边的门已配好，可参考）：
- `Collider2D`(Is Trigger) + `InteractableObject` + `SceneDoor` + 「按F」子物体。
- `SceneDoor.targetSceneName` 填目标场景（如出门→`Reality_Street`，必须在 Build Settings 里）。
- `targetSpawnId` 填目标场景里 `SceneSpawnPoint` 的 id。
- `InteractableObject.onInteract` 里接 `SceneDoor → Enter()`（要音效再加 `AudioCueTrigger → Play()`）。

---

## 4. 常见问题

- **按 F 没反应**：检查 Collider 的 Is Trigger、玩家有没有 `Player` Tag、`DialogueTrigger.startNodeId` 是否存在于 CSV、`onInteract` 是否接了 `TryStartDialogue`。
- **「按F」提示不出现/不消失**：子物体名字要是 `按F`/`按F查看` 等，且默认 Active 取消勾选。
- **头顶提示不出现**：玩家有没有 `PlayerPromptReceiver`、`PromptBubble` 有没有 `PlayerPromptView` 并绑好 TMP、物体 Collider 是不是 Trigger、`Trigger Chance` 是否太低。
- **提示文字镜像了**：`PromptBubble` 若是玩家子物体、而角色用翻转 localScale 转向，会镜像；给它单独做个不翻转的锚点。
- **改完丢了**：记得 `Ctrl/Cmd + S` 保存场景。
