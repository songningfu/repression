## 目标
- 实现 A2 对话系统完整链路：支持 CSV 导入生成对话图资源、运行时节点推进、基于应激度的选项过滤、打字机/跳过/加速、简版历史记录，以及可挂接到交互或剧情事件的启动入口。

## 变更点
- 新增 `DialogueGraphData`、`DialogueNodeData`、`DialogueChoiceData`、`DialogueChoiceGroupData`：作为运行时统一对话数据源，避免 UI 或业务层直接拼装对话结构。
- 新增 `DialogueCsvImportDefinition` 与编辑器导入工具：可把 `DialogueNodes.csv` / `DialogueChoices.csv` 解析为 `DialogueGraphData` 资源，并校验 `NodeId`、`ChoiceId`、`NextId` 与阈值合法性。
- 新增 `DialogueRunner`：负责启动对话、播放节点、在文本结束后显示选项或下一句按钮、在选择时调用 `MentalStatsManager.ModifyStress(...)` 回写应激度，并广播历史/控件状态事件。
- 新增 `DialogueView`、`DialogueChoiceButtonView`、`DialoguePortraitLibrary`：负责面板显示、打字机、跳过/加速、历史记录、选项按钮列表与头像 Key 映射，不直接写核心状态。
- 新增 `DialogueTrigger`：提供可复用的起始入口，便于按钮、交互物或剧情节点直接触发指定 `StartNodeId`。

## 验收方式（编辑器/运行时）
- 在 Project 中创建一个 `DialogueCsvImportDefinition` 资源，绑定两张 CSV，然后点击 Inspector 上的“生成 / 更新 DialogueGraphData”按钮，确认生成图资源且无校验报错。
- 在场景中放置一个对话面板并挂 `DialogueView`，手动补齐 `TMP_Text`、`Image`、`Button`、`ChoicesRoot` 与选项按钮 Prefab 引用；再把 `DialogueRunner` 绑定到同一套图资源与 `DialogueView`。
- 若需要头像显示，创建 `DialoguePortraitLibrary` 并把 CSV 中的 `PortraitKey` 映射到对应 `Sprite`；若不绑定该资源，系统会自动隐藏头像位。
- 进入 Play 后，通过 `DialogueTrigger.TryStartDialogue()` 或勾选 `DialogueRunner.playOnStart` 触发对话，验证文本打字机、点击跳过、加速切换、历史记录、选项阈值过滤与 Stress 回写是否正常。

## 风险与 TODO
- 当前系统已完整覆盖代码链路，但场景中的对话面板、选项按钮 Prefab、历史区和头像资源仍需要在 Inspector 中手动绑定；这是为了遵守“Editor First / 引用优于查找”的项目约定。
- `UnavailableMode` 目前作为可选 CSV 字段扩展支持 `Hidden / Disabled`，旧 CSV 不填写时会默认按 `Hidden` 处理；如后续策划需要更细的禁用文案或灰显样式，可在按钮 Prefab 上继续扩展。
- 当前历史记录为简版文本拼接，如果后续需要滚动列表、时间戳或富文本高亮，可以在不改核心状态机的前提下替换 `DialogueView` 表现层。

## 对接说明
- UI / 程序 B：请准备一个带 `Button + TMP_Text` 的选项按钮 Prefab，并在对话面板上补齐 `speakerNameText`、`dialogueText`、`historyText`、`nextButton`、`choicesRoot` 等引用。
- 策划：CSV 至少需要维护 `NodeId/SpeakerName/PortraitKey/Text/NextId` 与 `ChoiceId/ChoiceOrder/NodeId/OptionText/NextId/StressModifier/ThresholdLow/ThresholdHigh`；若要区分“隐藏/禁用”，可额外增加 `UnavailableMode` 列。
- 交互/剧情：外部只需要拿到 `DialogueRunner` 或 `DialogueTrigger`，调用 `StartDialogue(startNodeId)` / `TryStartDialogue()` 即可，不要直接操作 UI 文本或 Stress 数值。
